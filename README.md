# 👤 Facial Recognition System

A real-time facial recognition system built using Python and OpenCV. The project captures faces through a camera, detects facial features, and performs face recognition for identifying registered individuals.

---

## ✨ Features

- 📷 Real-time face detection
- 👤 Facial recognition using OpenCV
- 🎥 Camera-based recognition
- 🧠 Face matching and identification
- ⚡ Real-time processing
- 🖥️ Simple and easy-to-use system
- 🔐 Helps in identity verification
- 📁 Supports registered face data

---

- **OpenCV**

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Nanc199/Facial_Recognition_System.git
```

### 2. Navigate to the Project Directory

```bash
cd Facial_Recognition_System
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### macOS / Linux

```bash
source venv/bin/activate
```

### 5. Install Required Libraries

```bash
pip install opencv-python numpy
```

---

## ▶️ Run the Project

Navigate to the project folder:

```bash
cd Opencv
```

Then run the Python file containing the facial recognition application:

```bash
python filename.py
```

> Replace `filename.py` with the actual Python file name in the `Opencv` folder.

## 💡 How It Works

1. 📷 The system accesses the computer's camera.
2. 🔍 OpenCV detects faces from the camera feed.
3. 🧠 Facial features are processed for recognition.
4. 👤 The detected face is compared with registered face data.
5. ✅ If a matching face is found, the person is identified.
6. ❌ If no match is found, the face is treated as unknown.
7. 🖥️ The result is displayed in real time.

---

## 🧩 Main Components

### 📷 Camera Module

Captures live video frames from the system camera.

### 🔍 Face Detection

Detects human faces from the captured video using computer vision techniques.

### 🧠 Face Recognition

Processes detected facial features and compares them with registered face data.

### 👤 Identity Verification

Displays the identity of a recognized person or marks the face as unknown.
